# “职”此无忧 · ZCWY

> “让每一份兼职，都有可信的权益凭证。”

“职”此无忧是一个面向大学生兼职场景的权益保护与诚信激励平台。

我们尝试通过可信存证、智能合约与区块链，重新设计兼职中的信任关系。

学生认真完成工作，企业认真履行承诺，而每一个关键过程，都应该有迹可循。

## 你可以在这个 Demo 中看到

### 学生端

- 兼职工作台
- 岗位与投递进展
- 履约进度
- 工作成果提交
- 薪资状态
- 实践证书

### 企业端

- 任务管理
- 学生履约记录
- 成果验收
- 薪资结算
- 企业认证状态

### 权益保障

- 薪资托管
- 关键节点存证
- 完整证据链
- 智能合约模拟执行
- 可验证的实践记录

## 核心演示流程

```text
学生提交成果
→ 企业验收
→ 智能合约模拟结算
→ 薪资到账
→ 实践证书生成
```

一次兼职，不应该只留下一笔工资。

它也可以沉淀为一段可信、可验证的实践经历。

## 本地运行

运行环境需要 Node.js `^20.19.0` 或 `>=22.12.0`。

```sh
git clone https://github.com/onlytimeknows/zcwy.git
cd zcwy
npm install
npm run dev
```

## 项目状态

目前，“职”此无忧是一个可交互的产品概念原型。

项目中的业务数据、账号、区块链存证和智能合约执行均处于模拟环境。当前尚未接入真实区块链节点、支付系统、身份认证服务或生产后端。

这个 Demo 想验证的，并不是“能不能把区块链放进一个兼职平台”。

我们更关心的是另一件事：

技术能不能让原本依赖口头承诺的关系，变得更清楚、更可信，也更容易被证明。

## 开源背后的故事

这个项目最初诞生于一次大学生竞赛，是我们对大学生兼职权益保护的一次产品尝试。

但我们觉得，关于公平、信任和青年权益的想法，不必只停留在一份比赛材料或一个私人仓库里。

所以，我们决定把它公开出来。

这也是我第一次正式开源自己的项目。很高兴，第一个开源项目恰好从大学生兼职这样一个真实而具体的问题开始。
